# Features

## Document-style editor

Write forms naturally like a Notion doc. Insert blocks with `/` slash commands, edit inline, and drag to reorder.

## Block library

- **Inputs:** Short & Long text, Email, Phone, Number, URL, Date, Time, Address.
- **Choices & Scales:** Multiple Choice, Checkboxes, Dropdown, Multi-select, Star & Linear Ratings, NPS (Net Promoter Score), Opinion Scales, Matrix / Grid, and Drag-to-Rank.
- **Content & Embeds:** Headings (H1–H3), Paragraphs, Captions, Dividers, Images, and rich embeds (YouTube, Vimeo, Figma, Loom, Spotify).

## Conditional logic & page jumps

Show/hide questions based on respondent answers, branch across multi-page workflows, or jump straight to submit.

## Dynamic answer piping

Reference previous answers in any title or question prompt using `@mention` syntax.

## Custom scoring & quizzes

Assign point values to answers and calculate real-time scores or quiz results.

## Custom CSS engine

Deep styling control with granular CSS classes: `.q`, `.q1`, `.q-multi`, `.q-option`, `.q-badge`, `.q-label`.

## Form controls

Password protection, response limits, automated scheduling (close date/time), and draft auto-saving to local storage.

## Submissions & exports

Clean response dashboard with detailed submission breakdown and one-click CSV export.

## Self-hostable

Standalone lightweight container with PostgreSQL and Express. See [self-hosting](self-hosting.md).
